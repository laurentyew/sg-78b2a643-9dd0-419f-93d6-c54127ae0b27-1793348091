## What It Does

AI-powered comment and DM moderation/automation platform for social media. Core functions:
- Auto-hide spam, scam, and abusive comments in real time
- AI-powered replies in brand voice
- Keyword-triggered DM automation
- Sentiment and toxic language detection
- Multi-platform comment management dashboard

## Key Features

### Auto-Moderation
- Hide spam before customers see it
- Block bots, scam links, fake giveaways, abusive comments
- Real-time comment filtering
- Custom keyword filters (user-configurable)
- Works on Facebook & Instagram Ads specifically

### AI Replies
- Brand voice training from FAQs, products, tone
- Automatic responses to routine questions
- Sound on-brand, not robotic
- User-created reply templates/macros

### DM Automation
- Keyword-triggered instant DMs
- "link?", "price?", "send details" → auto-DM
- 3-step automation flows

### Sentiment Analysis
- Detect negative sentiment early
- Flag unhappy conversations for human intervention
- Catch issues before they escalate

### Multi-Platform Dashboard
- Manage Instagram, Facebook, YouTube in one place
- Unified inbox
- No tab-switching

### Analytics & Reporting
- Comment volume tracking
- Spam caught statistics
- Reply performance metrics
- Dashboard overview of moderation activity

### Team Features
- **User roles:** Admin and Moderator
- Team members can help manage comments
- Escalate sensitive messages to humans
- Flag for care, legal review, manual response
- **No team assignment feature** (roadmap consideration)
