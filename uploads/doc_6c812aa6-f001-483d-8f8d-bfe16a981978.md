## 0. Ground rules

1. **Never fabricate** product features, pricing, customer names, testimonials, statistics, integrations, or compliance claims. Every product fact must come from `PRODUCT_FACTS` (section 1). If a fact is missing, write `[CONFIRM: ...]` in the draft and list it in `OPEN_QUESTIONS.md`.

5. **Detect the stack first** (Next.js, Astro, WordPress, Webflow, etc.) and use its native conventions for routing, metadata, sitemap, and content (MDX/Markdown/CMS). State what you detected before writing code.
6. **Work in phases** (section 12). After each phase, output a short checklist of what was created and what remains.
7. Write in plain, specific, helpful language. Answer-first. No filler, no emoji, no "In today's digital landscape".

## 4. Technical SEO checklist (do this first)

- `robots.txt` allowing all crawlers including AI crawlers (GPTBot, ClaudeBot, PerplexityBot, Google-Extended) unless the owner objects; reference the sitemap.
- `sitemap.xml` (auto-generated, split by section if >500 URLs), with `lastmod`.
- `llms.txt` at root: product summary, key page URLs, pricing, supported platforms, comparison pages. Keep facts identical to the site.
- Canonical tag on every page; self-referencing.
- Unique `<title>` (<=60 chars) and meta description (<=155 chars) per page; primary term first.
- One `<h1>` per page matching intent. Logical H2/H3 hierarchy.
- Open Graph + Twitter card tags; generate OG images per page template.
- JSON-LD schema:
  - Site-wide: `Organization`, `WebSite`.
  - Homepage/product: `SoftwareApplication` (applicationCategory `BusinessApplication`, offers from `PRICING`).
  - Guides: `Article` + `HowTo` where steps exist + `FAQPage`.
  - Comparison pages: `FAQPage`; do **not** add fake `AggregateRating`.
  - Breadcrumbs: `BreadcrumbList` everywhere.
- `hreflang` for /ms and /zh with `x-default`.
- Core Web Vitals: LCP < 2.5s, CLS < 0.1, INP < 200ms. Optimize images (WebP/AVIF, width/height set, lazy-load below the fold). Self-host fonts.
- Server-render or statically generate all marketing/content pages (no client-only content).
- Clean 404, 301 redirects for any old URLs, HTTPS, no duplicate www/non-www.
- Internal linking module: related guides, "Automate this with Social Kirin" CTA block, breadcrumbs, hub links.
- Analytics + Search Console + Bing Webmaster verification placeholders (do not invent IDs).

## 11. Content-writing spec (applies to every page)

- **Search intent first:** the page's first screen must answer the query.
- **Length follows need,** not a word count target.
- **E-E-A-T:** author byline (Laurent Yew or named team member), "Last updated" date, link to sources, show real product screenshots.
- **Headings** are descriptive questions or statements, not clever.
- **Links:** 3-6 internal links per page with descriptive anchor text; outbound links to authoritative sources (Meta Help Center, regulator sites) where relevant.
- **Images:** descriptive filenames, alt text, no stock fluff.
- **CTA:** one primary CTA per page, consistent wording.
- **Brand voice:** clear, practical, confident, non-hype. Neutral on competitors.
